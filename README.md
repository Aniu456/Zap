# 一闪 Zap

一闪是常驻 macOS 菜单栏的效率工具。功能都用全局快捷键唤起，要的是快。

这一版有两件事：

- **应用启动器**。模糊搜索这台 Mac 上安装的应用，回车打开。
- **剪贴板历史**。一闪运行时记下复制过的文本和图片。选中一条，会粘贴进当前最前面的应用，而不只是复制回剪贴板。

没有账号，没有统计，也不需要网络。历史只存在你自己的电脑上。

英文名是 Zap，界面是简体中文，面向 zh-Hans-SG。

## 还没做：截图

截图留到后面的版本，这一版没有。计划是：

- 快捷键做区域截图
- 用箭头、方框、文字、马赛克标注
- 把截图钉在其他窗口上面
- 截完自动复制，并出现在剪贴板历史里

快捷键注册和剪贴板记录是分开的，图片现在就会进历史。后面加截图不用把这一版推倒重来。

## 环境

- macOS 14 或更高
- Xcode 16 或更高

## 打开并运行

1. 克隆这个仓库。
2. 用 Xcode 打开 `Zap.xcodeproj`。
3. 顶部 scheme 选 **Zap**。
4. 选中 Zap target 的 Signing & Capabilities，把 Team 设成你的 Apple ID。只在本机运行时，也可以选 Sign to Run Locally。
5. 按 Run。

一闪不会出现在程序坞里。看屏幕最上方菜单栏里的图标：四角选区，中间一道闪电。

辅助功能权限和代码签名绑在一起。换了签名之后，系统里要重新勾选一次。

单元测试在 ZapTests。菜单 Product → Test，或按 ⌘U。

## 权限

把历史直接粘贴到当前应用，需要**辅助功能**：

系统设置 → 隐私与安全性 → 辅助功能 → 打开「一闪」或 Zap。

可以在菜单栏或设置里点「去授权」。系统会把一闪加进列表，你再打开开关。有的系统要退出并重新打开一闪，自动粘贴才会生效。

没有这项权限时：

- 启动器照常使用。
- 剪贴板历史照常浏览和搜索。选中一条会放回系统剪贴板，再按 ⌘V 粘贴。

全局快捷键走系统热键，一般不靠辅助功能。如果某个组合没反应，用菜单栏打开功能，再到设置里换一个。

## 默认快捷键

| 功能 | 快捷键 |
| --- | --- |
| 启动器 | ⌥Space |
| 剪贴板历史 | ⌥⇧Space |

两个都打开同一块浮动面板，只是模式不同。再按一次当前模式的快捷键，面板会关掉。

面板里：

| 按键 | 作用 |
| --- | --- |
| ↑ ↓ | 选择 |
| ↩ | 打开应用，或粘贴这条历史 |
| esc | 关闭 |

菜单栏的「设置…」可以改快捷键。点按键框，按下新的组合，至少带一个修饰键。Esc 取消。

## 剪贴板历史记什么

- 纯文本
- 图片（PNG、JPEG、TIFF）。以后的截图只要进了系统剪贴板，就会出现在这里
- 复制文件时，记下路径

最多 200 条，重启之后还在。大约超过 20 万字的文本，以及大于 8 MB 的图片会跳过。标记为密码或临时内容的剪贴板不会记。

文件在：

```
~/Library/Application Support/Zap/
```

## 工程

```
Zap.xcodeproj          用 Xcode 打开这个
Zap/App                菜单栏应用入口，不占程序坞
Zap/Launcher           扫描本机应用并做模糊搜索
Zap/Clipboard          监听剪贴板、保存历史、模拟粘贴
Zap/Palette            启动器和历史共用的浮动面板
Zap/Hotkeys            全局快捷键，可在设置里改
Zap/Capture            只留给以后的截图，这一版没有实现
ZapTests               模糊匹配和历史去重的单元测试
```
